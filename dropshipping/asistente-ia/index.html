    Cómo usarlo

      🔌 Conectar con Claude

      1. Entra a platform.claude.com con la cuenta que tiene el saldo.
      2. En la sección de claves de API (API Keys) crea una clave nueva solo para esta app. Empieza con sk-ant-.
      3. Pégala aquí y pulsa «Guardar y probar». La prueba no gasta saldo.

      Si no la recuerdas, se borra al cerrar la página. Si la recuerdas, otros archivos HTML que abras en este mismo navegador desde tu computadora podrían leerla: usa una clave exclusiva para esta app y revócala en la Consola si dejas de usarla.

      ¿Cómo funciona?

      1. 1Cuéntanos de tu tienda. Nombre, qué vendes, a quién y qué IA usas.
      2. 2Elige qué crear. La lista sigue el orden para lanzar una tienda.
      3. 3Copia y pega en tu IA, o descarga el archivo. Cada resultado trae sus pasos de uso.

      💬 Prompt

      Una instrucción completa para una tarea puntual (por ejemplo, escribir la página de un producto). La pegas en un chat nuevo y la IA responde.

      🧩 Skill

      Un «asistente experto» que instalas una vez. En Claude se sube como archivo ZIP y Claude lo usa solo cuando lo necesita. En ChatGPT o Gemini se pega como instrucciones de un GPT, Proyecto o Gem.

      🔁 Loop

      Un proceso por ciclos: la IA hace un paso, mide, aprende y repite hasta cumplir una meta (por ejemplo, encontrar 3 productos buenos). Al final de cada ciclo escribes CONTINUAR. Algunos tienen versión para Claude Code, que se repite sola cada cierto tiempo.

      ▶ Ejecutar con Claude (opcional)

      Si tienes saldo en la Consola de Claude, conecta una clave en el paso 3 y pulsa ▶ Ejecutar con Claude en cualquier resultado. Haiku es muy barato y rápido; Sonnet da más calidad y cuesta unas 20 veces más. Cada respuesta muestra su costo estimado.

      Las marcas en el texto

      • [COMPLETAR: …]: un dato que no llenaste. La IA te lo preguntará.
      • [VERIFICAR: …]: la IA debe usar esta marca cuando no está segura de un dato. Revísalo antes de publicar o gastar dinero.

      Todo funciona en tu navegador. Solo si conectas Claude (paso 3), lo que ejecutes se envía a la API de Anthropic. Los textos legales que genere la IA son borradores y deben revisarse con un abogado.
